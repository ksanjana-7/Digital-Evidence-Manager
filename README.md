# CBP---Digital-Evidence-Manager


1. Admin (full access)

Manage users
View all cases
View all evidence
View the complete audit log (access history)
Can access any evidence

2. Investigator

Create cases and manage the cases assigned to them
Register new evidence by selecting a file
Transfer evidence to another user (only if they currently hold it)
Verify evidence integrity using the SHA-256 hash(SHA-256 is a hashing algorithm. It reads a file and produces a 64-character code, like a fingerprint:)
View the history relevant to their cases
What is hashed :
1. The evidence file’s contents
2. Passwords


3. Forensic Officer

View the evidence assigned to them
Verify evidence integrity (hash check)
Record forensic actions
Transfer evidence onward when permitted
